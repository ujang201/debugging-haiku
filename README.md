One haiku about debugging, in the 5-7-5 syllable shape, written by `main.ts` to `/output/entry.txt`:

> Breakpoint holds its breath
> the log line blinks, then goes still
> the bug wore my face

Run it with Node 22:

```sh
node main.ts
```
